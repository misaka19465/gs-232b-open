# 会话隔离的校准交互

实现见 [`command_calibration.c`](../src/core/command_calibration.c)，状态布局及时间常量见 [`calibration.h`](../include/gs232b/calibration.h)。交互由控制核心维护，绑定发起者的完整 `session_id + generation`，不使用阻塞终端循环。所有权、停止优先级及调用边界见[控制核心](command-control.md)。

## 入口与输入

`O/O2/F/F2` 在执行时取得或检查控制权；要求两轴无动作、输出已知全停、没有已加载的序列或上传预约，待使用轴已启用且 ADC 采样新鲜。O/O2 不要求已有有效零点；F/F2 需要可换算的当前位置，F2 同时检查 AZ 和 EL。入口和实际执行均校验前置条件，拒绝不会覆盖旧动作或存储。

| 状态 | 发起会话输入 | 结果 |
| --- | --- | --- |
| O/O2 等待确认 | `Y` / `YES`，不区分大小写 | 当场重新读取对应 ADC，校验新鲜度、时间戳及最小跨度；保存成功后应用 RAM 零点并返回 `Completed\r\n`，然后退出。 |
| O/O2 等待确认 | `N` / `NO` / 空行 | 返回一个 CR，取消并保留旧零点。 |
| O/O2 等待确认 | 其他非空 GS 行 | 返回协议错误，继续等待，不执行普通命令，不延长期限。 |
| F/F2 显示 | 空行 | 返回一个 CR 并结束显示。 |
| F/F2 显示 | 其他非空 GS 行 | 返回协议错误，继续显示，不延长期限。 |
| 任一交互 | 任一活动会话的独立 `A/E/S` | 退出交互，按原停止语义处理，仅向停止来源响应；A/E 保留控制者，S 撤权。 |

旁路会话的空行只得到普通 CR；`N` 仍查询序列，均不能取消交互。旁路 `Y/YES` 不能保存。普通状态下独立 `Y/YES/NO` 返回错误。O/O2 与确认可以同批排队，但确认始终按实际执行时的发起会话和交互状态解释。

## 保存与显示

零点保存通过 [`gs232b_motion_save_zero`](../include/gs232b/motion.h) 执行：先证明全停，重新调用采样端口，使用该次有效采样而非提示前的滤波窗口，调用既有版本化持久化层写入 `ZERO_AZ` 或 `ZERO_EL`，成功后才在同一串行边界应用 RAM 配置。无效、陈旧、未来或倒退的样本，跨度不足、存储读取失败、写失败或提交中断均保留原零点，不输出完成提示。存储端口必须满足失败保留旧活动记录的既有契约，不引入新的记录格式。

F/F2 进入即输出一帧，随后每 500ms 向发起会话输出当前读数；迟到只发当前帧，不补积压帧。F 使用 `AZ=aaa\r\n`，F2 使用 `AZ=aaa  EL=eee\r\n`；沿用 P36/P45 和 N/S 中心映射。显示不产生运动，也不调用任何持久化写入。

## 期限与清理

两种交互均在 60 秒没有有效交互输入后输出一次协议错误并退出。周期输出、非法行、普通查询、旁路输入及重复取权均不延长期限。期限使用单调微秒差值；时钟倒退同样取消。到期判断先于普通请求执行，迟到确认不能保存。

确认、取消、超时、采样或运动故障会作废发起会话尚未提交的半行，继续静默排空至其终止 CR；没有半行时直接恢复普通解析。所有停止沿用全局 epoch 失效机制，清掉旧队列和半行。发起会话断开时全停、撤权、清交互及输入，不转发结果给旁路会话；旁路断开不干扰当前交互。槽位复用使用新的 generation，旧确认无效。

F/F2 每次 tick 检查采样，失效时输出一次错误并退出，不能继续显示旧值。异步响应入队失败时关闭核心会话并全停、撤权；传输层清理连接。UART 无可观测的主机关闭事件，依靠相同的 60 秒期限或空行退出。

[组合入口](app-lifecycle.md)已接入 UART/WebSocket 与控制核心。未实测参数时仍可校准零点，但不会因此解除运动门禁；真实反馈、电位器范围和机械行为仍需上板验证。
