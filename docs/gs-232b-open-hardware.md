# GS-232B 硬件与实板验收

## 硬件资料

- 主控位号：`U3`。
- 模组型号：`ESP32-C3-WROOM-02U-N4`。
- 模组工作电源：`3.3 V`；Flash 为 4MB。
- 原理图：[SCH.svg](SCH.svg)；物料清单：[BOM.csv](BOM.csv)。
- 下表的“管脚号”对应 U3 的符号及焊盘编号，“GPIO”对应固件使用的 GPIO 编号。两种编号不可混用。
- 输入、输出方向均以 ESP32-C3 为参照；本文描述板级硬件分配。

## 方向输出与共享 SPI

旋转器的四路方向控制和 W5500 复位由 U5（74HC595D）输出。ESP32-C3 使用 GPIO4 发送数据、GPIO3 提供移位时钟、GPIO2 锁存输出。

| 输出位 | U5 管脚号 | 网络 | 实际功能 |
| --- | --- | --- | --- |
| Q0 / bit 0 | 15 | `UP_EL_DRV` | 经 R10 驱动 Q1（AO3400A），控制仰角上转 `UP_EL`。 |
| Q1 / bit 1 | 1 | `DOWN_EL_DRV` | 经 R11 驱动 Q2（AO3400A），控制仰角下转 `DOWN_EL`。 |
| Q2 / bit 2 | 2 | `CW_AZ_DRV` | 经 R12 驱动 Q3（AO3400A），控制方位顺时针转动 `CW_AZ`。 |
| Q3 / bit 3 | 3 | `CCW_AZ_DRV` | 经 R13 驱动 Q4（AO3400A），控制方位逆时针转动 `CCW_AZ`。 |
| Q4 / bit 4 | 4 | `W5500_RST` | 连接 W5500 Lite 的 nRESET（U6 第 8 脚），低电平复位、高电平释放。 |
| Q5 / bit 5 | 5 | 未连接 | 未使用。 |
| Q6 / bit 6 | 6 | 未连接 | 未使用。 |
| Q7 / bit 7 | 7 | 未连接 | 未使用。 |

四路方向输出均采用 N 沟道 MOSFET 对地拉低：相应 `DRV` 为高电平时，MOSFET 导通，将外部控制线拉至地；为低电平时关闭。每路栅极串联电阻为 100 Ω，并配有 100 kΩ 下拉电阻。

U5 的 OE# 使用 R6、C20 构成的上电延时网络，MR# 经 R7（10 kΩ）上拉；这两个信号均未分配独立的 ESP32-C3 GPIO。

本板连接旋转器控制箱的外部控制接口，不直接驱动电机绕组或市电。方向输出模拟按键接地，全部信号共地，没有光耦或隔离 ADC。同轴相反方向不能同时有效；换向须先停止并等待控制箱实测确定的间隔。PWM 降为零不能代替清方向位。

W5500 访问也会改变 595 移位寄存器，因此每次更新并行输出都须重新移入完整 8 位，再产生 STCP 上升沿；发送到锁存之间不得插入 Ethernet 事务。GPIO2 只作锁存，W5500 复位由 bit4 控制；bit5～7 保持零。所有网络时钟也会到达 595，SPI 频率须同时满足两者在 3.3V 下的时序和板级信号完整性，不能直接采用 W5500 的最高频率。

## 外部接口

| 功能 | H1（2×5） | PS1（6 针加屏蔽脚） | U2（DIN-804） |
| --- | --- | --- | --- |
| 仰角上 / 下 | 1 / 3 | 无 | 3 / 5 |
| 方位 CW / CCW | 2 / 4 | 1 / 2 | 2 / 4 |
| SPEED 输出 | 5、6 同一网络 | 3 | 无 |
| 方位反馈 | 8 | 4 | 6 |
| 仰角反馈 | 7 | 无 | 1 |
| 信号地 | 9、10 | 5 | 8 |
| 其他 | — | 6 未接；7、8、9 为接地壳脚 | 7 未接；9、10 为接地壳脚 |

PS1、U2 和 H1 对应网络直接并联，并非相互隔离的多套接口。不能同时接两台方位控制箱，尤其不能让两个模拟反馈输出互相驱动。U2 不带 SPEED；H1 两个 SPEED 脚相连，板上只有一个有效调速通道。

USB1 是原生 USB Serial/JTAG；USB2 是 CH340K 控制串口，逻辑电平为 3.3V，不是 RS-232。CH340K 的 DTR#、RTS#、CTS# 未连接，主机须关闭硬件流控，也不能通过这些线判断掉线。GPIO20 虽标为 RXD，实际分配给 PWM，不能被 UART0 控制台占用。

## 反馈与调速电路

两路反馈分别经 4.7kΩ / 3kΩ 分压和 220Ω 串阻、1µF ∥ 1nF 滤波进入 ADC1。标称分压比 `3 / (4.7 + 3) ≈ 0.389610`，外部 4.5V 对应 ADC 约 1.753V；等效阻抗约 2.051kΩ，时间常数约 2.054ms。每路给控制箱带来约 7.7kΩ 直流负载，应在接上本板后调整，不能沿用悬空测量刻度。

| 轴 | 输入 | 固定满量程 | 零点与满量程调整 |
| --- | --- | --- | --- |
| AZ | GPIO1 / ADC1_CH1 | 外部 4.5V → 450° | O 确认保存零点，F 显示并配合外部电位器调整 |
| EL | GPIO0 / ADC1_CH0 | 外部 4.5V → 180° | O2 确认保存零点，F2 显示并配合外部电位器调整 |

角度为 `θ = θFS × (Vadc − V0) / (VFS − V0)`，V0 各轴独立保存，VFS 为固定分压满量程。ADC 使用芯片出厂校准电压，不以 `raw / 4095 × 3.3V` 换算；C3 最高衰减档的有效范围约到 2.5V，3.3V 供电不是 ADC 满量程。没有额外数字两点标定，F/F2 不保存满量程。

分压和滤波不构成隔离或完整过压保护，角度输入没有独立 TVS/精密钳位。断线可能与合法近零端点相似，静止时无法保证靠一次低读数识别，软件故障检测不能替代电气保护。

调速路径为 GPIO20 → R28 10kΩ → C35 1µF / R31 100kΩ 滤波 → LM358 非反相放大 → R26 100Ω → SPEED。R31 同时构成直流分压：

```text
D 为 PWM 占空比，0 ≤ D ≤ 1
Vfilter ≈ 3.3 × D × 100 / 110 = 3.000 × D V
G = 1 + 5.1 / 10 = 1.51
Vopamp ≈ 4.530 × D V
τ ≈ (10kΩ ∥ 100kΩ) × 1µF ≈ 9.09ms
Vspeed ≈ Vopamp − Iload × 100Ω
```

标称空载上限约 4.53V，接近稳定需约 5τ（45ms），均受器件、电源和控制箱负载影响。只有方位有调速通道；X1～X4 的实际转速及近目标减速效果取决于控制箱和负载。板上没有 SPEED 电压反馈，驱动接纳 PWM 不表示模拟输出或转速已经达到请求值。

LM2665 从板上 5V 倍压，经 R27/C33/C34 滤波形成 9V_AUX 给 LM358 供电；这是网络名，不是稳压 9V 保证，也不表示 SPEED 为 9V。LM358 第二路只是约 1.65V 的空载跟随器，没有接到 SPEED 或 ADC，不构成反馈通道。

## 启动与复位边界

DC1、USB1 VBUS、USB2 VBUS 经保护与 SS34 二极管汇到板上 5V，AMS1117-3.3 再产生 3.3V。板上 5V 受压降与负载影响；DC1 没有 12V→5V 降压，不能沿用原机 12V 适配器。Ethernet 与 Wi-Fi 同时工作时还需核对 3.3V 峰值、稳压器压差/发热及 9V_AUX 纹波。

U5 OE# 为 C20 1µF 接 3.3V、R6 1MΩ 接地，上电跳变使其暂时偏高再回落，标称时间常数 1 秒；它不是 MCU 可控安全使能，慢上电或短暂掉电不能保证关断。MR# 仅经 R7 10kΩ 上拉，未连接 EN，而且清移位寄存器并不直接清输出锁存器。

应用启动会尽早锁存 0x00、PWM=0，随后释放 W5500 复位。**MCU 复位、卡死、下载或 JTAG 暂停时，硬件不保证立即停机。** 595 可能保持先前方向，GPIO2 上拉也可能产生锁存边沿；门极下拉不能压过 595 的高电平。软件看门狗无法覆盖所有这些情况，须评估受复位或硬件看门狗支配、默认禁用的 OE# 或输出使能，并实测验证。

GPIO2/8/9 是启动绑带脚，分别由 R4/R1/R8 上拉。SW1 接 GPIO9，SW2 接 EN；成品用户不可触及，不作为配网或恢复入口。台架维护下载时保持 GPIO9 为低再复位，释放后进入下载流程；不得因此跳过运动输出的复位安全验证。

## 实板验收

实板验收覆盖以下项目。每次记录固件提交、SDK/配置、控制箱与 W5500 模块版本、测试负载、原始 USB 日志及测量轨迹；协议 UART 不混入诊断日志。

| 验收项 | 需要记录的结果 |
| --- | --- |
| 接线与供电 | 连接器通断、接口方向、3.3V/5V/9V_AUX 的峰值、纹波和温升 |
| SPI 与输出 | SCLK/MOSI/nSS/STCP、复位 bit4、方向/PWM 的脉宽、建立保持；网络流量和硬复位时无误锁存 |
| 反馈与调速 | 两轴独立注入 0～4.5V、噪声与校准；带载 SPEED 电压、纹波、响应、四档转速和减速效果 |
| 机械参数 | 到位容差、换向等待、无进展/反向判定、最大运行时间及其与控制箱响应的一致性 |
| 串口与网络 | 四档真实波特率捕获、重连、DHCP、AP+STA 切换、同/不同子网双网回包与 ARP、配置试运行及断电恢复 |
| 堆栈与延迟 | 启动及 4 WS+UART 上传/查询/慢客户端/扫描/NVS 压力下的最小空闲堆、最大连续块、任务栈高水位、控制周期迟到与耗时 |
| 停止与故障 | 完整 S 的 CR 接收到方向锁存清零/PWM=0 的延迟、SPI/NVS 真实失败、反馈断线/冻结/反向及故障后不自动续跑 |
| 复位与失调度 | EN/软件复位、掉电、下载、JTAG 暂停与真实 SDK 任务 WDT 时的电平和机械响应；不能把应用会话超时当硬件断电保证 |

延迟与堆栈余量按实机速度、反馈与机械停机要求判定，运行数据以实板记录为准。AP 凭据与 UART 恢复路径随设备交付记录维护。
