# GS-232B 硬件引脚与功能说明

## 1. 适用对象与编号

- 主控位号：`U3`。
- 模组型号：`ESP32-C3-WROOM-02U-N4`。
- 工作电源：`3.3 V`。
- 下表的“管脚号”对应 U3 的符号及焊盘编号，“GPIO”对应固件使用的 GPIO 编号。两种编号不可混用。
- 输入、输出方向均以 ESP32-C3 为参照；本文描述板级硬件分配。

## 3. 74HC595 间接控制功能

转台的四路方向控制和 W5500 复位由 U5（74HC595D）输出。ESP32-C3 使用 GPIO4 发送数据、GPIO3 提供移位时钟、GPIO2 锁存输出。

| 输出位 | U5 管脚号 | 网络 | 实际功能 |
| --- | --- | --- | --- |
| Q0 / bit 0 | 15 | `UP_EL_DRV` | 经 R10 驱动 Q1（AO3400A），控制仰角上转 `UP_EL`。 |
| Q1 / bit 1 | 1 | `DOWN_EL_DRV` | 经 R11 驱动 Q2（AO3400A），控制仰角下转 `DOWN_EL`。 |
| Q2 / bit 2 | 2 | `CW_AZ_DRV` | 经 R12 驱动 Q3（AO3400A），控制方位顺时针转动 `CW_AZ`。 |
| Q3 / bit 3 | 3 | `CCW_AZ_DRV` | 经 R13 驱动 Q4（AO3400A），控制方位逆时针转动 `CCW_AZ`。 |
| Q4 / bit 4 | 4 | `W5500_RST` | 连接 W5500 Lite 的 nRESET（U6 第 8 脚），低电平复位、高电平释放。 |
| Q5 / bit 5 | 5 | 未连接 | 未使用。 |
| Q6 / bit 6 | 6 | 未连接 | 未使用。 |
| Q7 / bit 7 | 7 | 未连接 | 未使用。 |

四路方向输出均采用 N 沟道 MOSFET 对地拉低：相应 `DRV` 为高电平时，MOSFET 导通，将外部控制线拉至地；为低电平时关闭。每路栅极串联电阻为 100 Ω，并配有 100 kΩ 下拉电阻。

U5 的 OE# 使用 R6、C20 构成的上电延时网络，MR# 经 R7（10 kΩ）上拉；这两个信号均未分配独立的 ESP32-C3 GPIO。

## 4. 功能分组与使用要点

### 4.1 以太网与共享串行总线

- W5500 使用 GPIO4（MOSI）、GPIO5（MISO）、GPIO3（SCLK）、GPIO8（CS）、GPIO10（INT）。
- W5500 的复位由 74HC595 的 Q4 控制，更新该位时需保留其他输出位的状态。
- GPIO4 和 GPIO3 同时连接 W5500 与 74HC595。访问 W5500 时，74HC595 的移位寄存器也会收到数据和时钟，但只有 GPIO2 出现锁存上升沿时才会改变并行输出。
- 更新 74HC595 时，应保持 GPIO8 为高电平，使 W5500 处于未选中状态，再移入完整输出字节并产生锁存脉冲。

### 4.2 USB 与串口

- USB1 直接连接 GPIO18、GPIO19，使用 ESP32-C3 原生 USB Serial/JTAG。
- USB2 经 D2 静电保护连接 CH340K，再通过 GPIO6、GPIO7 与 ESP32-C3 通信。
- GPIO6 是 ESP32-C3 发送端，GPIO7 是接收端；固件需将所用 UART 的 TX、RX 分别映射到这两个 GPIO。
- GPIO20 虽然在模组上标为 RXD，但本板分配给转速 PWM；GPIO21 标为 TXD，但未连接外设。
- CH340K 的 DTR#、RTS#、CTS# 均未连接。

### 4.3 角度反馈与转速控制

- GPIO1 采集方位角 `ANGLE_AZ`；GPIO0 采集仰角 `ANGLE_EL`。
- 两路角度输入的标称分压比均为 `3 / (4.7 + 3) ≈ 0.3896`；忽略负载影响时，外部反馈电压约为 ADC 引脚电压的 `2.5667` 倍。两个信号分别进入 ADC1_CH1、ADC1_CH0，独立换算，分压比相同不意味着共用角度量程或零点。
- 固件自动使用芯片出厂校准数据修正 ADC 电压。两路反馈满量程均为外部 4.5V、分压后约 1.753V，分别对应方位 450°和仰角 180°。方位零点通过 `O` 保存，仰角零点通过 `O2` 保存；满量程通过 `F/F2` 显示，用户调整控制箱对应反馈输出电位器，不采集或保存额外满量程标定点。
- GPIO20 输出 `SPEED_PWM`，经低通滤波和 LM358 放大后形成转速控制电压 `SPEED`。PWM 频率、占空比与转速的对应关系由固件设定。

### 4.4 启动与复位

- SW1 接 GPIO9，按下为低电平；SW2 接 EN，按下复位。
- GPIO2、GPIO8、GPIO9 同时承担启动配置功能。板上分别由 R4、R1、R8 上拉，运行后 GPIO2 用作锁存、GPIO8 用作片选、GPIO9 用作按键输入。
- 正常启动时保持 GPIO9 为高电平；需要进入下载模式时，按住 SW1，再按下并释放 SW2，随后释放 SW1。
