# GS-232B 控制协议

本文描述本项目固件的对外行为。与 YAESU GS-232B 原机相比，本板通过 USB 转串口及 WebSocket 接入，不提供 DB-9 RS-232 电平或 CTS 流控；帮助布局、并发仲裁和故障处理采用下述约定。管理扩展见[管理与配网](management-commands.md)，物理接线见[硬件说明](gs-232b-open-hardware.md)。

## 连接与分帧

| 入口 | 连接方式 |
| --- | --- |
| USB2 / UART1 | CH340K 虚拟串口；1200/2400/4800/9600 bit/s、8N1、关闭硬件流控。GPIO6 为 TX、GPIO7 为 RX。 |
| Ethernet / Wi-Fi STA | `ws://<接口IPv4>/ws/gs232b`，TCP 80；两个接口可同时使用。 |
| USB1 | 原生 USB Serial/JTAG，仅调试日志，不接收控制命令。 |
| SoftAP | 仅配网页和管理连接，不接纳 GS 运动命令。 |

UART 在启动后的 15 秒内通过三个同速完整 CR 匹配波特率；未匹配时使用上次有效记录，无有效记录则回退到 9600。协议就绪后发送一次 `Connect OK\r\n`。网络会话在 Upgrade 后发送同样的连接提示，不等待串口匹配窗口。

命令以 CR（`0x0D`）结束，不回显，不输出常驻提示符。推荐只发送 CR；紧跟 CR 的一个 LF 被忽略，单独 LF 非法。GS 命令及确认输入不区分 ASCII 大小写，忽略首尾 ASCII 空格；命令与首参数必须紧邻，数字字段之间允许多个空格。BS、DEL、Tab、方向键、NUL 和非 ASCII 字节均非法，不提供行编辑。

角度和步进间隔必须写足三位十进制，不接受正负号、小数或缩写。GS 行在 CR 前最多 16384 字节；连续 2 秒没有新字节时返回一次错误，随后丢弃到下一 CR。其他非法字节或超长行在 CR 时报告一次错误，不执行合法前缀。低速长序列的总传输时间可超过 2 秒。

WebSocket 接受 Text 或 Binary 数据消息，响应使用 Binary；负载为原始协议字节，不加 JSON、NUL 或额外 CR。命令可跨消息，一条消息也可含多条命令；支持 continuation，Ping/Pong 不属于协议输入。单帧或累计消息最多 16384 字节，行末 CR 可放在下一消息。无效分片以 1002 关闭，消息过大以 1009 关闭。控制及管理连接共用四个网络连接名额，超限拒绝新连接；UART 独立可用。

浏览器 Origin 仅接受本连接目标 IPv4 的 `http://a.b.c.d` 或 `http://a.b.c.d:80`；无 Origin 的原生客户端可连接。不接受域名别名、跨站、`null` 或 HTTPS Origin。接口地址变化或失效会关闭该接口的旧会话，重连不续跑动作。传输每 5 秒 Ping、15 秒无匹配 Pong 关闭；发送超时为 2 秒。应用命令看门狗与传输心跳独立，见[管理命令](management-commands.md#控制权故障与看门狗)。

## 命令与响应

下表省略命令末尾 CR，响应中的 `\r`、`\n` 表示实际控制字节。普通成功无数据时仅返回一个 CR，错误为 `?>\r\n`；带正文响应不再额外追加确认。响应表示命令接纳，不表示机械已到位；没有异步 `OK` 或 `DONE`。

| 命令 | 行为或完整响应 |
| --- | --- |
| `R` / `L` | 方位顺时针 / 逆时针持续运动 |
| `U` / `D` | 仰角上 / 下持续运动 |
| `A` / `E` | 停止方位 / 仰角，清除序列与校准交互，另一轴已接纳动作可继续 |
| `S` | 两轴全停、清序列和交互、撤销控制权 |
| `Maaa` | 方位单点定位，例如 `M001` |
| `Waaa eee` | 双轴单点定位，例如 `W180 090`；不能省略方位参数 |
| `X1`～`X4` | 选择四档方位速度，运动中可调整；仰角没有 PWM 调速，`Y1`～`Y4` 返回错误 |
| `C` | `AZ=aaa\r\n` |
| `B` | `EL=eee\r\n` |
| `C2` | `AZ=aaa  EL=eee\r\n`，字段间固定两个 ASCII 空格 |
| `N` | `=nnnn=mmmm\r\n`，分别为已下发点序号 / 序列总点数；无序列时均为 `0000` |
| `H` / `H2` | 方位 / 仰角命令帮助，每行以 CRLF 结束 |
| `H3` | 显示模式帮助及当前 `mode 360 Degree` / `mode 450 Degree`、`N Center` / `S Center` |
| `P36` / `P45` | 选择 360° / 450° 方位显示模式，断电保留 |
| `Z` | P36 下切换 N/S 中心并保存；P45 下仅返回 CR |
| `O` / `O2` | 方位 / 仰角零点确认交互 |
| `F` / `F2` | 持续显示方位 / 双轴读数，供外部电位器调整 |
| 空行 | 普通状态仅返回 CR，不停止或清序列；校准中按下文处理 |

## 控制权与停止

两轴共用一个控制会话，第一条合法且成功执行的写控制命令可自动取权。其他会话可查询，运动、速度、显示和校准写入被拒绝；查询和无效输入不占用或延长控制权。两轴已知全停、无待运行序列或交互时，空闲 2 秒自动释放；运动、等待 T 和校准期间保持控制权。有效 M/W 上传预约暂停空闲释放，不提前取得控制权或提交目标。

任何活动 GS 会话均可发送完整独立的 `A\r`、`E\r`、`S\r`。停止优先于普通请求；A/E 保留控制者，S 撤权。停止作废旧排队动作及未完成输入，残留后缀丢弃到下一 CR，不会在停止后重新启动；已接纳的停止不因来源关闭而撤回。同周期 A 与 E 停两轴但保留控制权，只有 S 按全停撤权处理。

控制者断线、接收丢字节或运动故障会清任务、撤权并尝试全停；旁路会话出错只清自身输入。CH340K 没有 DTR/RTS 连线，无法以主机关闭串口或拔 USB2 推定断线。负载中的字母 S、未带 CR 的 S 或丢弃中的半行不构成停止命令。

响应只返回来源会话，并保持输入顺序，错误不越过先前请求。停止动作可先执行，排队查询随后读取停机后的状态；周期校准帧只发给发起者。响应或发送资源耗尽时关闭来源，控制者关闭按失联处理。软件停机依赖任务调度和外设提交；输出失败保留“输出未知”，网络停止不能替代硬件急停，见[启动与复位边界](gs-232b-open-hardware.md#启动与复位边界)。

## 角度与显示模式

机械方位行程 `p` 从逆时针端起顺时针增加，范围 0～450°；仰角范围 0～180°。P36/P45/Z 只改变显示及目标解释，不改变电气换算或机械限位。初始设置为 P45 / N Center。

| 模式 | 方位显示 |
| --- | --- |
| P45 | `p`，保留超过 360° 的行程 |
| P36 / S Center | `p mod 360` |
| P36 / N Center | `(p + 180) mod 360` |

P36 目标选择机械范围及软件限位内距当前位置最近的等价行程，等距时取较小值；`360` 与 `000` 表示同一方位。长序列首点按当前位置选解，后续点以前一点连续选解；需要明确指定绕行位置时使用 P45。角度四舍五入为整数度，半度向大值取整；P36 取整后归一为 000～359。

模式或中心的实际变更要求两轴无动作、输出已知全停、序列计时未运行且无校准；保存成功后清序列。重复当前模式及 P45 下 Z 不写入新设置、不清序列。

仰角被明确禁用时，B 返回 `EL=000\r\n`，C2 的 EL 为 000；W 所有仰角参数必须为 000，仅控制方位，U/D/O2/F2 被拒绝，E/S 仍可用。已启用轴的反馈无效时，涉及该轴的查询返回错误，不能用零或旧读数代替；N、帮助与停止仍可用。

## 定时序列

长格式 M 加载 2～3800 个方位点；W 加载 2～1900 对方位/仰角。首字段为 001～999 秒间隔，不是第一个目标；000 非法。两种格式共用一份序列：

```text
Msss aaa bbb ccc ...<CR>
Wsss aaa eee bbb fff ...<CR>
```

只有完整 CR、全部参数、权限和运行条件验证通过后才提交；普通拒绝保留旧序列、目标和计时。加载成功立即下发首点，N 为 1/总数，不等待机械到位；T 开始后续点计时。

例如以下各行实际以 CR 结束：

```text
M010 150 140 100
T
N
```

以 T 实际接纳时刻为 t0，第 2 点在 t0+10 秒、第 3 点在 t0+20 秒下发；N 依次为 `=0001=0003`、`=0002=0003`、`=0003=0003`。序号表示已下发目标数，末点下发后定位仍可继续。运行中重复 T 仅返回 CR，不重置计时；无序列或已经结束时 T 返回错误，须重新加载才能开始新一轮。

截止时间始终从 t0 计算，不等待上一点到位，也不累积调度延迟。迟到达到完整一个步进间隔、时钟倒退或后续目标无法接纳时，清序列、撤权并尝试全停，锁定故障，不补发过期点。清故障后不恢复旧序列。

| 操作 | 序列及轴动作 |
| --- | --- |
| 新长格式 M/W 成功 | 原子替换任意类型旧序列，下发首点并等待 T |
| 单点 M/W 成功 | 清旧序列和序号，执行新定位 |
| M/W 替换旧序列 | 停止旧序列拥有而新目标未涉及的轴；独立的另一轴手动动作保留 |
| 裸 M/W（含只有空格的参数） | 先检查权限，再清序列、尝试全停并返回错误；无权请求无副作用 |
| R/L/U/D/A/E | 清序列，只改变指定轴，另一轴已接纳动作可继续 |
| S、控制者关闭或运动故障 | 清序列、旧任务和控制权 |
| 查询、帮助、普通空行、X1～X4 | 保留序列、序号和计时 |
| 完成后空闲或显式释放控制权 | 保留末点序号和数据；重启会清除序列 |

## 校准

操作前先用控制箱手动将旋转器移到指定位置；校准命令不会自动移动旋转器。两轴须无动作、输出已知全停，无已加载序列、上传或故障，所用轴已启用并有新鲜采样。O/O2 可在缺零点或运动参数未经实测时使用；F/F2 需要有效位置，F2 同时检查两轴。

| 命令 | 操作及响应 |
| --- | --- |
| O | 将方位移到逆时针端；提示 `AZoffset\r\nare you sure? yes or no\r\n` |
| O2 | 将仰角移到 0°；提示 `ELoffset\r\nare you sure? yes or no\r\n` |
| Y / YES | 仅在发起会话等待确认时有效；保存确认瞬间重新取得的采样，成功返回 `Completed\r\n` 并退出 |
| N / NO / 空行 | 在零点确认中取消并返回 CR，保留旧零点 |
| F | 立即输出 `AZ=aaa\r\n`，此后每 500ms 输出当前帧；方位满量程调整到 450° |
| F2 | 立即输出 `AZ=aaa  EL=eee\r\n`，此后每 500ms 输出当前帧；仰角满量程调整到 180° |
| 空行 | 结束 F/F2 显示并返回 CR，不保存满量程 |

两轴的满量程固定为外部反馈 4.5V，接上本板后调整对应外部电位器；F/F2 不保存额外满量程点。Y/YES 的采样、跨度或存储校验失败时保留旧零点，返回错误并退出。

交互只接受发起会话输入，旁路 Y/YES/NO 无法确认或取消；旁路 N 查询序列，空行仅返回普通 CR。发起者的其他非空 GS 行返回错误并保持交互；任一活动 GS 会话的独立 A/E/S 都退出交互并执行停止，仅向停止来源响应。普通状态下独立 Y/YES/NO 返回错误。

交互期限为 60 秒；周期输出、非法输入、旁路请求和重复取权不续期，迟到确认不能保存。超时、运动故障或 F/F2 采样失效时返回一次错误并退出；显示不补发积压读数。确认或退出后，发起者的半行丢弃至下一 CR。发起会话断开时清交互、撤权并尝试全停；旁路断开不影响它。UART 需靠空行或超时退出，不能检测主机关闭。
