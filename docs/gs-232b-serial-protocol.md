# GS-232B 串口协议

本文说明 YAESU GS-232B 原机的串口接口、命令、响应格式和交互过程。

## 1. 接口模型

GS-232B 使用可由终端直接操作的 ASCII 文本命令接口。它允许从键盘输入，也允许控制程序发送相同命令；除了普通的控制与查询，还具有帮助输出、校准确认和持续显示校准读数的交互过程。

因此，可以把它理解为具有少量交互状态的串口命令解释器。普通操作仍然使用确定的命令字和参数格式；不能因为终端交互的存在，就假定它支持通用 shell 的语法或编辑功能。

基本规则：

- 命令字母允许大写或小写。
- 命令以回车 `CR`，即 `0x0D`，结束。
- 向设备发送命令时不要附加 `LF`，即 `0x0A`。
- 设备不回显收到的命令。
- 每条命令之后，设备回送 `CR`；如果命令还返回数据，则另有 `LF`。
- 非法命令返回错误标记，并清空输入缓冲区。
- 角度参数以度为单位，使用三位十进制数，不足三位时在左侧补零。

本文以 `?>` 表示错误标记。该标记表示错误，不应将 `>` 视为每条命令前都会出现的常驻提示符。

控制程序不能依赖运动命令的空响应判断设备是否接收成功，也不能因没有收到 `OK` 而反复重发定位命令。查询结果用于读取位置，不能替代独立的运动故障判断。

## 2. 串口连接与建立通信

### 2.1 物理接口和线路参数

| 项目 | 参数 |
| --- | --- |
| 接口 | RS-232C，设备端为 DB-9 公头 |
| 连接线 | 直通 RS-232C 连接线 |
| 波特率 | 1200 到 9600 bit/s；设备自动匹配计算机的设置。 |
| 数据位 | 8 |
| 校验 | 无 |
| 停止位 | 1 |
| 流控 | 硬件流控，使用 CTS。 |

设备端串口针脚如下：2 为 Tx Data，3 为 Rx Data，5 为信号地，7 为 RTS，8 为 CTS。发送、接收方向以设备端为准。

加载含步进间隔的角度序列时，必须启用 CTS 硬件流控。

### 2.2 上电时的波特率匹配

1. 设置计算机串口参数并建立连接。
2. 开启 GS-232B 电源。
3. 在上电后的 15 秒内，多次发送回车，使设备匹配计算机的波特率。
4. 匹配成功时，设备显示 `Connect OK`。

波特率保留与再次上电的行为：

- 已设置的波特率会保持，直到下一次改变通信速度。
- 再次上电后，如果约 15 秒内发送回车，设备完成连接并显示 `Connect OK`，随后可以接收命令。
- 如果上电约 15 秒内没有发送回车，设备使用已设置的波特率启动，并自动显示 `Connect OK`。

`Connect OK` 是建立通信时的消息，不能当作每条操作命令的确认消息。

控制程序开始时，向设备发送一次回车，清理设备缓冲区，同时清理计算机的接收缓冲区。这是开始通信时的同步操作，与使用 `M` 或 `W` 清除已加载角度序列不同。

## 3. 命令和响应记法

- 本文命令表省略结尾的 `CR`。例如 `C` 在传输时为 `C\r`，即十六进制 `43 0D`。
- `aaa`、`bbb`、`ccc`：三位方位角；在相应模式下为 `000` 到 `360`，或 `000` 到 `450`。
- `eee`：三位仰角，范围 `000` 到 `180`。
- `sss`：三位步进间隔，单位为秒，范围为 `001` 到 `999`。
- 多个数字参数之间使用空格；例如 `W180 090\r`。
- 表中的响应是响应正文；除明确列出的内容外，不用这些展示形式推定额外空行、提示符或逐字节时序。

## 4. 转动、停止与定位

| 命令 | 行为 |
| --- | --- |
| `R` | 开始方位顺时针转动，即向右转动。 |
| `L` | 开始方位逆时针转动，即向左转动。 |
| `A` | 停止方位转动。 |
| `U` | 开始仰角向上转动。 |
| `D` | 开始仰角向下转动。 |
| `E` | 停止仰角转动。 |
| `S` | 停止两轴，取消当前操作；删除已设置的步进角度序列。 |
| `Maaa` | 立即开始转向给定方位角。 |
| `Waaa eee` | 立即开始转向给定的方位角和仰角。 |
| `X1` | 选择最低方位转速。 |
| `X2` | 选择方位中速 1。 |
| `X3` | 选择方位中速 2。 |
| `X4` | 选择最高方位转速。 |

定位角度必须写足三位。例如，方位 1 度使用 `M001`，方位 180 度、仰角 90 度使用 `W180 090`。改变仰角的定位命令也必须提供方位角，不能省略 `W` 命令中的方位参数。

`Xn` 用于支持调速的 DXA/SDX 方位转台，可以在转动过程中发送，并立即生效。

上述转动命令不返回 `OK` 文本。常规命令结束时的回车规则见第 1 节；协议未定义转动完成时的异步 `OK` 或 `DONE` 消息。

## 5. 角度与步进状态查询

| 命令 | 响应正文 | 含义 |
| --- | --- | --- |
| `C` | `AZ=aaa` | 当前方位角。 |
| `B` | `EL=eee` | 当前仰角。 |
| `C2` | `AZ=aaa EL=eee` | 当前方位角及仰角。 |
| `N` | `=nnnn=mmmm` | 当前步进点序号，以及已存储的步进点总数。 |

`C2` 的角度顺序为先方位、后仰角；`N` 的数量顺序为先当前序号、后总数。表中的一个空格用于分隔字段，不表示原机固定只输出一个空格；接收程序应容忍 `AZ` 与 `EL` 字段之间的多个空格。

`N` 的两个数字字段各占四位；零状态表示为 `=0000=0000`。

`N` 中的一个点，在 `M` 长格式下是一个方位角，在 `W` 长格式下是一对方位角与仰角。因此，最大总数分别为 3800 和 1900。

加载长格式 `M` 或 `W` 并启动 `T` 后，使用 `N` 查询步进进度。尚未输入角度序列时，两个字段均为零；当前序号等于总数表示步进已经到达最后一项，不能仅据此判断机械位置已经到位。

## 6. 帮助与方位显示模式

| 命令 | 行为 |
| --- | --- |
| `H` | 输出方位控制相关的命令列表。 |
| `H2` | 输出仰角控制相关的命令列表。 |
| `H3` | 输出显示模式命令列表以及当前显示模式。 |
| `P36` | 设置为 360 度方位显示模式。 |
| `P45` | 设置为 450 度方位显示模式。 |
| `Z` | 在 360 度模式下切换 North/South 显示中心；450 度模式下忽略该命令。 |

这些模式设置在断电后保留。

`H3` 展示当前是 360 度还是 450 度模式，并包含 North/South 中心状态。显示内容包括 `mode 450 Degree` / `mode 360 Degree` 以及 `N Center` / `S Center`。

## 7. 多点定时跟踪

### 7.1 加载方位序列：`M` 长格式

```text
Msss aaa bbb ccc ...<CR>
```

- `sss` 是步进间隔，而不是第一个方位角。
- 后续参数为方位角；一条命令可存储 2 到 3800 个方位角。
- 间隔范围为 `001` 到 `999` 秒，方位角范围为当前显示模式允许的 `000` 到 `360` 或 `450`。
- 所有数字使用三位十进制，各数字参数之间用空格分隔。
- 收到命令后，设备先转向第一个方位角，随后等待 `T`，而不是收到长格式后立即执行完整序列。

示例：

```text
M010 150 140 100 080 090<CR>
T<CR>
```

第一条命令先转向 150 度；`T` 启动之后，设备按照 10 秒的步进间隔，依次执行后续的 140、100、80、90 度位置。

### 7.2 加载方位和仰角序列：`W` 长格式

```text
Wsss aaa eee bbb fff ...<CR>
```

这里 `bbb` 为下一点的方位角，`fff` 为下一点的仰角，仅用不同占位字母区分前后两个点。

- 第一个数字为步进间隔，后续数字必须组成完整的方位角、仰角配对。
- 最多存储 1900 对角度。
- 间隔范围为 `001` 到 `999` 秒；方位角范围为 `000` 到 `360` 或 `450`；仰角范围为 `000` 到 `180`。
- 不完整的角度对会导致错误，不能只提供方位角或仰角。
- 收到命令后，设备先转向第一对角度，随后等待 `T`。

示例：

```text
W010 190 080 150 060 200 030<CR>
T<CR>
```

第一条命令先转向方位 190 度、仰角 80 度；之后按 10 秒的步进间隔执行后续的 `(150, 60)`、`(200, 30)` 两个位置。

### 7.3 启动与查询

`T` 启动已经加载的长格式 `M` 或 `W` 序列。它不是位置参数，也不用于在没有已加载序列时建立一个新序列。

加载序列后，设备先就位到第一点并等待 `T`。输入 `T` 后启动步进，按设定间隔依次执行后续点。

步进进度使用 `N` 查询；字段含义见第 5 节。协议未定义设备主动逐点上报。

### 7.4 数据清除与保留范围

| 操作 | 结果 |
| --- | --- |
| 再次发送 `M` | 已有的 `M` 序列被清除/替换。 |
| 单独发送 `M`，不带参数 | 返回错误提示，但仍清除存储的角度数据。 |
| 再次发送 `W` | 已有的 `W` 序列被清除/替换。 |
| 单独发送 `W`，不带参数 | 返回错误提示，但仍清除相关序列。 |
| `S` | 停止两轴，并删除已设置的步进序列。 |
| 关闭相关控制器或重启 GS-232B | 已加载的序列失效；GS-232B 断电会清除数据。 |

模式设置的断电保留与角度序列的断电清除是不同规则，不能合并为统一的“所有设置均保留”或“所有设置均清除”。

## 8. 校准的交互过程

校准操作以转台已被手动移至指定位置为前提。发送校准命令本身不等于要求设备自动移动到校准端点。

### 8.1 零点校准：`O` 和 `O2`

| 命令 | 对象 | 手动准备位置 |
| --- | --- | --- |
| `O` | 方位零点偏置 | 将转台移到逆时针端。 |
| `O2` | 仰角零点偏置 | 将转台移到 0 度水平位置。 |

注意：命令字是英文字母 `O`，不是数字 `0`。

交互顺序如下：

1. 发送 `O<CR>` 或 `O2<CR>`。
2. 设备请求确认，显示下表中的提示内容。
3. 操作者发送 `Y<CR>`。
4. 设备保存校准设置，显示 `Completed`，退出对应零点校准过程。

| 命令 | 确认提示内容 |
| --- | --- |
| `O` | `AZoffset`，以及 `are you sure? yes or no`。 |
| `O2` | `ELoffset`，以及 `are you sure? yes or no`。 |

这意味着 `O` / `O2` 具有等待后续输入的状态，不能把它们写成收到命令后立即保存零点的单次请求。`Y` 在这里是确认输入，不应与普通运动命令混淆。

### 8.2 满量程读数校准：`F` 和 `F2`

| 命令 | 显示内容 | 操作方式 |
| --- | --- | --- |
| `F` | 方位读数 `AZ=aaa` | 手动设定指定位置，调整相应控制器或适配器上的电位器，使显示读数达到对应型号的目标。 |
| `F2` | 方位与仰角读数 `AZ=aaa EL=eee` | 手动把仰角移到 180 度，调整仰角输出电位器，使仰角读数达到 180。 |

`F` 的校准目标：

| 转台 | 校准时的方位显示目标 |
| --- | --- |
| DXA/DXC/SDX 系列及 G-5500 | 450。 |
| G-400、G-5400B、G-5600B | 180。 |

`F` / `F2` 是允许在读数显示过程中调整外部模拟输出的校准过程。校准结束时发送单独的回车，退出校准显示。

## 9. 通信注意事项

- 发送命令时不要附加 `LF`。
- 程序开始时发送一次回车，清理设备的输入缓冲区，并清理主机接收缓冲区。
- 发送含步进间隔的长序列时，启用 CTS 硬件流控。
- 如果大量数据传输出现异常，可以降低通信速度。
- 在较低波特率下，不要密集连续发送 `N` 或 `C`；命令接收中断可能使响应输出被截断，并影响转台控制。

使用 `M` 或 `W` 定位时，在距离停止位置约 15 度处降低速度控制电压，用于减速。这里的“约 15 度”是减速触发位置，不是转台停止误差。
