# GS-232B 串口协议与本项目行为约定

本文说明 YAESU GS-232B 的串口命令、响应格式和交互过程。第 1～9 节描述串口协议及本项目采用的校准目标，第 10 节列出原机仍未确定的边界，第 11 节规定本项目的具体行为。本项目约定不代表原机具有相同实现。

## 1. 接口模型

GS-232B 使用可由终端直接操作的 ASCII 文本命令接口。它允许从键盘输入，也允许控制程序发送相同命令；除了普通的控制与查询，还具有帮助输出、校准确认和持续显示校准读数的交互过程。

因此，可以把它理解为具有少量交互状态的串口命令解释器。普通操作仍然使用确定的命令字和参数格式；不能因为终端交互的存在，就假定它支持通用 shell 的语法或编辑功能。

基本规则：

- 命令字母允许大写或小写。
- 命令以回车 `CR`，即 `0x0D`，结束。
- 向设备发送命令时不要附加 `LF`，即 `0x0A`。
- 设备不回显收到的命令。
- 每条命令之后，设备回送 `CR`；如果命令还返回数据，则另有 `LF`。
- 非法命令返回错误标记，并清空输入缓冲区。
- 角度参数以度为单位，使用三位十进制数，不足三位时在左侧补零。

错误标记写作 `?>` 或 `? >`，内部空格的实际传输形式尚未确定。该标记表示错误，不应将 `>` 视为每条命令前都会出现的常驻提示符。

控制程序不能依赖运动命令的空响应判断设备是否接收成功，也不能因没有收到 `OK` 而反复重发定位命令。查询结果用于读取位置，不能替代独立的运动故障判断。

## 2. 串口连接与建立通信

### 2.1 物理接口和线路参数

| 项目 | 参数 |
| --- | --- |
| 接口 | RS-232C，设备端为 DB-9 公头 |
| 连接线 | 直通 RS-232C 连接线 |
| 波特率 | 1200 到 9600 bit/s；设备自动匹配计算机的设置。 |
| 数据位 | 8 |
| 校验 | 无 |
| 停止位 | 1 |
| 流控 | 硬件流控，使用 CTS。 |

设备端串口针脚如下：2 为 Tx Data，3 为 Rx Data，5 为信号地，7 为 RTS，8 为 CTS。发送、接收方向以设备端为准。

加载含步进间隔的角度序列时，必须启用 CTS 硬件流控。

### 2.2 上电时的波特率匹配

1. 设置计算机串口参数并建立连接。
2. 开启 GS-232B 电源。
3. 在上电后的 15 秒内，多次发送回车，使设备匹配计算机的波特率。
4. 匹配成功时，设备显示 `Connect OK`。

波特率保留与再次上电的行为：

- 已设置的波特率会保持，直到下一次改变通信速度。
- 再次上电后，如果约 15 秒内发送回车，设备完成连接并显示 `Connect OK`，随后可以接收命令。
- 如果上电约 15 秒内没有发送回车，设备使用已设置的波特率启动，并自动显示 `Connect OK`。

`Connect OK` 是建立通信时的消息，不能当作每条操作命令的确认消息。

控制程序开始时，向设备发送一次回车，清理设备缓冲区，同时清理计算机的接收缓冲区。这是开始通信时的同步操作，与使用 `M` 或 `W` 清除已加载角度序列不同。

## 3. 命令和响应记法

- 本文命令表省略结尾的 `CR`。例如 `C` 在传输时为 `C\r`，即十六进制 `43 0D`。
- `aaa`、`bbb`、`ccc`：三位方位角；在相应模式下为 `000` 到 `360`，或 `000` 到 `450`。
- `eee`：三位仰角，范围 `000` 到 `180`。
- `sss`：三位步进间隔，单位为秒，范围为 `001` 到 `999`。
- 多个数字参数之间使用空格；例如 `W180 090\r`。
- 表中的响应是响应正文；除明确列出的内容外，不用这些展示形式推定额外空行、提示符或逐字节时序。

## 4. 转动、停止与定位

| 命令 | 行为 |
| --- | --- |
| `R` | 开始方位顺时针转动，即向右转动。 |
| `L` | 开始方位逆时针转动，即向左转动。 |
| `A` | 停止方位转动。 |
| `U` | 开始仰角向上转动。 |
| `D` | 开始仰角向下转动。 |
| `E` | 停止仰角转动。 |
| `S` | 停止两轴，取消当前操作；删除已设置的步进角度序列。 |
| `Maaa` | 立即开始转向给定方位角。 |
| `Waaa eee` | 立即开始转向给定的方位角和仰角。 |
| `X1` | 选择最低方位转速。 |
| `X2` | 选择方位中速 1。 |
| `X3` | 选择方位中速 2。 |
| `X4` | 选择最高方位转速。 |

定位角度必须写足三位。例如，方位 1 度使用 `M001`，方位 180 度、仰角 90 度使用 `W180 090`。改变仰角的定位命令也必须提供方位角，不能省略 `W` 命令中的方位参数。

`Xn` 选择方位转速，可以在转动过程中发送，并立即生效。

上述转动命令不返回 `OK` 文本。常规命令结束时的回车规则见第 1 节；协议未定义转动完成时的异步 `OK` 或 `DONE` 消息。

## 5. 角度与步进状态查询

| 命令 | 响应正文 | 含义 |
| --- | --- | --- |
| `C` | `AZ=aaa` | 当前方位角。 |
| `B` | `EL=eee` | 当前仰角。 |
| `C2` | `AZ=aaa EL=eee` | 当前方位角及仰角。 |
| `N` | `=nnnn=mmmm` | 当前步进点序号，以及已存储的步进点总数。 |

`C2` 的角度顺序为先方位、后仰角；`N` 的数量顺序为先当前序号、后总数。表中的一个空格用于分隔字段，不表示原机固定只输出一个空格；接收程序应容忍 `AZ` 与 `EL` 字段之间的多个空格。

`N` 的两个数字字段各占四位；零状态表示为 `=0000=0000`。

`N` 中的一个点，在 `M` 长格式下是一个方位角，在 `W` 长格式下是一对方位角与仰角。因此，最大总数分别为 3800 和 1900。

加载长格式 `M` 或 `W` 并启动 `T` 后，使用 `N` 查询步进进度。尚未输入角度序列时，两个字段均为零；当前序号等于总数表示步进已经到达最后一项，不能仅据此判断机械位置已经到位。序号起始值及加载后尚未启动时的字段变化未确定；本项目的确切定义见第 11.3 节。

## 6. 帮助与方位显示模式

| 命令 | 行为 |
| --- | --- |
| `H` | 输出方位控制相关的命令列表。 |
| `H2` | 输出仰角控制相关的命令列表。 |
| `H3` | 输出显示模式命令列表以及当前显示模式。 |
| `P36` | 设置为 360 度方位显示模式。 |
| `P45` | 设置为 450 度方位显示模式。 |
| `Z` | 在 360 度模式下切换 North/South 显示中心；450 度模式下忽略该命令。 |

这些模式设置在断电后保留。

`H3` 展示当前是 360 度还是 450 度模式，并包含 North/South 中心状态。显示内容包括 `mode 450 Degree` / `mode 360 Degree` 以及 `N Center` / `S Center`。完整帮助屏幕的逐字节格式未确定。

## 7. 多点定时跟踪

### 7.1 加载方位序列：`M` 长格式

```text
Msss aaa bbb ccc ...<CR>
```

- `sss` 是步进间隔，而不是第一个方位角。
- 后续参数为方位角；一条命令可存储 2 到 3800 个方位角。
- 间隔范围为 `001` 到 `999` 秒，方位角范围为当前显示模式允许的 `000` 到 `360` 或 `450`。
- 所有数字使用三位十进制，各数字参数之间用空格分隔。
- 收到命令后，设备先转向第一个方位角，随后等待 `T`，而不是收到长格式后立即执行完整序列。

示例：

```text
M010 150 140 100 080 090<CR>
T<CR>
```

第一条命令先转向 150 度；`T` 启动之后，设备按照 10 秒的步进间隔，依次执行后续的 140、100、80、90 度位置。

### 7.2 加载方位和仰角序列：`W` 长格式

```text
Wsss aaa eee bbb fff ...<CR>
```

这里 `bbb` 为下一点的方位角，`fff` 为下一点的仰角，仅用不同占位字母区分前后两个点。

- 第一个数字为步进间隔，后续数字必须组成完整的方位角、仰角配对。
- 最多存储 1900 对角度。
- 间隔范围为 `001` 到 `999` 秒；方位角范围为 `000` 到 `360` 或 `450`；仰角范围为 `000` 到 `180`。
- 不完整的角度对会导致错误，不能只提供方位角或仰角。
- 收到命令后，设备先转向第一对角度，随后等待 `T`。

示例：

```text
W010 190 080 150 060 200 030<CR>
T<CR>
```

第一条命令先转向方位 190 度、仰角 80 度；之后按 10 秒的步进间隔执行后续的 `(150, 60)`、`(200, 30)` 两个位置。

### 7.3 启动与查询

`T` 启动已经加载的长格式 `M` 或 `W` 序列。它不是位置参数，也不用于在没有已加载序列时建立一个新序列。

加载序列后，设备先就位到第一点并等待 `T`。输入 `T` 后启动步进，按设定间隔依次执行后续点。第一次切换相对于收到 `T` 的精确时刻尚未确定。

步进进度使用 `N` 查询；字段含义见第 5 节。协议未定义设备主动逐点上报。

### 7.4 数据清除与保留范围

| 操作 | 结果 |
| --- | --- |
| 再次发送 `M` | 已有的 `M` 序列被清除/替换。 |
| 单独发送 `M`，不带参数 | 返回错误提示，但仍清除存储的角度数据。 |
| 再次发送 `W` | 已有的 `W` 序列被清除/替换。 |
| 单独发送 `W`，不带参数 | 返回错误提示，但仍清除相关序列。 |
| `S` | 停止两轴，并删除已设置的步进序列。 |
| 关闭相关控制器或重启 GS-232B | 已加载的序列失效；GS-232B 断电会清除数据。 |

模式设置的断电保留与角度序列的断电清除是不同规则，不能合并为统一的“所有设置均保留”或“所有设置均清除”。

## 8. 校准的交互过程

校准操作以转台已被手动移至指定位置为前提。发送校准命令本身不等于要求设备自动移动到校准端点。

### 8.1 零点校准：`O` 和 `O2`

| 命令 | 对象 | 手动准备位置 |
| --- | --- | --- |
| `O` | 方位零点偏置 | 将转台移到逆时针端。 |
| `O2` | 仰角零点偏置 | 将转台移到 0 度水平位置。 |

注意：命令字是英文字母 `O`，不是数字 `0`。

交互顺序如下：

1. 发送 `O<CR>` 或 `O2<CR>`。
2. 设备请求确认，显示下表中的提示内容。
3. 操作者发送 `Y<CR>`。
4. 设备保存校准设置，显示 `Completed`，退出对应零点校准过程。

| 命令 | 确认提示内容 |
| --- | --- |
| `O` | `AZoffset`，以及 `are you sure? yes or no`。 |
| `O2` | `ELoffset`，以及 `are you sure? yes or no`。 |

上面的四步是语义顺序，不是一个已经确定所有空格和换行位置的原始串口转储。

这意味着 `O` / `O2` 具有等待后续输入的状态，不能把它们写成收到命令后立即保存零点的单次请求。`Y` 在这里是确认输入，不应与普通运动命令混淆。

回答其他文本、回答否定、等待超时或在此状态下发送其他命令的完整行为尚未确定。

### 8.2 满量程读数校准：`F` 和 `F2`

| 命令 | 显示内容 | 操作方式 |
| --- | --- | --- |
| `F` | 方位读数 `AZ=aaa` | 手动将方位移到 450 度，调整方位反馈电位器，使显示读数达到 450。 |
| `F2` | 方位与仰角读数 `AZ=aaa EL=eee` | 手动把仰角移到 180 度，调整仰角输出电位器，使仰角读数达到 180。 |

本项目两路反馈统一以 4.5V 为满量程，分别对应方位 450 度和仰角 180 度。

`F` / `F2` 是允许在读数显示过程中调整外部模拟输出的校准过程。校准结束时发送单独的回车，退出校准显示。显示刷新周期未确定。

## 9. 通信注意事项

- 发送命令时不要附加 `LF`。
- 程序开始时发送一次回车，清理设备的输入缓冲区，并清理主机接收缓冲区。
- 发送含步进间隔的长序列时，启用 CTS 硬件流控。
- 如果大量数据传输出现异常，可以降低通信速度。
- 在较低波特率下，不要密集连续发送 `N` 或 `C`；命令接收中断可能使响应输出被截断，并影响转台控制。

使用 `M` 或 `W` 定位时，在距离停止位置约 15 度处降低速度控制电压，用于减速。这里的“约 15 度”是减速触发位置，不是转台停止误差。

## 11. 本项目的确定行为

### 11.1 串口与输入规则

本板的控制串口为 CH340K 连接的 UART1，默认使用 `9600 bit/s、8N1、无流控`。CH340K 的握手线没有接入 MCU，不实现 CTS 流控，也不复制原机上电 15 秒的自动波特率匹配。串口就绪后输出一次 `Connect OK\r\n`，随后直接接收命令。该消息表示串口协议入口就绪，不表示转台已经校准或可以运动。

| 项目 | 本项目约定 |
| --- | --- |
| 大小写 | 命令字及校准确认输入不区分 ASCII 大小写；响应使用下文规定的大小写。 |
| 行结束 | `CR` 提交一条命令；紧跟该 `CR` 的一个 `LF` 被忽略，兼容 `CRLF`，不产生第二条空命令。发送端仍推荐只发 `CR`。 |
| 单独的 `LF` | 不作为命令结束符；除上述 `CRLF` 情况外，按非法控制字符处理。 |
| 空行 | 普通命令状态下只返回 `\r`，不停止运动、不清除序列。交互校准状态下的空行按第 11.4 节处理。 |
| 空格 | 忽略行首、行尾的 ASCII 空格 `0x20`；数字参数之间允许一个或多个 ASCII 空格。 |
| 命令与首参数 | 按规范紧邻，例如 `M180`、`W180 090`；不接受 `M 180`、`C 2` 或 `P 45`。 |
| 数字 | 角度和间隔严格使用三位十进制；不接受符号、小数、少位、多位或数字后缀。`X1`～`X4` 等固定命令按各自语法处理。 |
| 编辑按键 | `BS`、`DEL`、方向键、Tab、历史和补全均不支持；收到这些控制字节即将当前行标为非法。 |
| 非文本字节 | NUL、其他未支持的控制字节和非 ASCII 字节使整行非法；不得把 NUL 当成字符串结束而执行前半行。 |
| 行长度 | `CR` 之前最多 16384 字节，包含空格。最大规范长序列占 15204 字节，因此允许完整的 3800 个方位角或 1900 对角度。 |
| 半行超时 | 从最后一个输入字节起，连续 5 秒没有后续字节且尚未收到 `CR`，返回一次错误并进入丢弃状态；收到下一次 `CR` 后恢复。不是整条长序列必须在 5 秒内发送完。 |

除半行超时外，非法字节或超长行都丢弃到该行的 `CR`，再返回一次错误；同一行不逐字节重复报错，也不从错误行的后缀重新识别命令。终止丢弃状态的 `CR` 不再产生空行响应。

先完成整行的语法、参数数量、范围、轴能力及运行状态校验，再更新目标或序列。不允许收到一个合法角度后先转动，再发现后续参数有误。普通非法命令保持原目标、原序列和校准值不变；不带参数的 `M/W` 是第 11.3 节明确规定的例外。

UART 接收溢出、帧错误等会丢失报文字节的故障，按通信故障处理：停止两轴、清除序列并退出校准，丢弃到下一次 `CR` 后再接收命令，返回一次错误。不能继续执行被截断的报文。

### 11.2 固定输出格式与帮助

本项目不回显输入，不输出常驻提示符，不额外插入空行。输出帧如下，表中的 `\r`、`\n` 表示实际控制字节：

| 情况 | 完整输出 |
| --- | --- |
| 普通无数据命令成功 | `\r` |
| 非法命令、非法参数或当前状态不允许 | `?>\r\n` |
| `C` | `AZ=aaa\r\n` |
| `B` | `EL=eee\r\n` |
| `C2` | `AZ=aaa  EL=eee\r\n`，两个字段之间固定两个 ASCII 空格。 |
| `N` | `=nnnn=mmmm\r\n` |

查询、帮助及校准有正文时，正文自带规定的行尾，不再追加一个独立的确认回车。普通运动命令只返回一个 `CR`，不返回 `CRLF`、`OK` 或转动完成通知。错误标记固定无内部空格，字节为 `3F 3E 0D 0A`。

帮助采用本项目的简明命令表，不要求复制原机屏幕布局。下面每行均以 `CRLF` 结束；不包含代码块边界、首尾空行或提示符。

`H`：

```text
R / L : Azimuth clockwise / counterclockwise
A : Stop azimuth
S : Stop all and clear sequence
Maaa : Set azimuth
Msss aaa bbb ... : Load azimuth sequence
C / C2 : Read azimuth / azimuth and elevation
X1 / X2 / X3 / X4 : Azimuth speed
T / N : Start sequence / read sequence index and count
O / F : Azimuth offset / calibration display
H / H2 / H3 : Azimuth / elevation / display help
```

`H2`：

```text
U / D : Elevation up / down
E : Stop elevation
S : Stop all and clear sequence
Waaa eee : Set azimuth and elevation
Wsss aaa eee bbb fff ... : Load azimuth/elevation sequence
B / C2 : Read elevation / azimuth and elevation
T / N : Start sequence / read sequence index and count
O2 / F2 : Elevation offset / calibration display
```

`H3` 的前三行固定为：

```text
P36 : 360 Degree mode
P45 : 450 Degree mode
Z : Toggle N/S center in 360 Degree mode
```

随后输出 `mode 360 Degree` 或 `mode 450 Degree` 一行，再输出 `N Center` 或 `S Center` 一行。450 度模式下中心字段展示保存的 360 度中心选项，不参与该模式的角度换算。

### 11.3 序列、序号与计时

`M` 和 `W` 共用一份序列存储，不能同时保留两种序列。`M` 长格式接受 2～3800 点，`W` 长格式接受 2～1900 对；步进间隔 `000` 一律拒绝，不解释为立即步进或默认间隔。

| 操作或状态 | 本项目约定 |
| --- | --- |
| 无序列 | `N` 返回 `=0000=0000\r\n`。 |
| 长格式加载成功 | 原子替换任意类型的旧序列，取消旧计时，向新序列第 1 点下发目标并等待 `T`；`N` 立即变为 `=0001=总点数`，不等待到位。 |
| 首次 `T` | 接受时刻为 `t0`，不等待首点机械到位；第 2 点在 `t0 + sss` 秒下发，第 `i` 点在 `t0 + (i-1) × sss` 秒下发。 |
| 正在计时再次收到 `T` | 只返回 `CR`，保持原计时起点、序号和目标，不重新开始。 |
| 序号推进 | 每次向运动控制器下发一个点时更新当前序号。序号表示已经下发的目标点，不表示已完成定位的点数。 |
| 最后一点已下发 | 停止步进计时，保留最后目标与序列；`N` 保持总数/总数，机械定位仍可继续。 |
| 无序列或序列已结束时 `T` | 返回错误；重新加载序列后才能开始新一轮。 |
| 单点 `Maaa` 或 `Waaa eee` | 取消计时，清除任意类型的旧序列及序号，再执行新定位。 |
| 单独的 `M` 或 `W` | 取消计时、停止两轴、清除共用序列，随后返回错误。只含空格的参数也属于这种情况。 |
| `S` | 取消计时、停止两轴、清除共用序列，`N` 归零。 |
| `R/L/U/D/A/E` | 取消计时并清除序列，只改变命令指定轴的运动；另一轴继续完成已经下发的目标或手动运动。 |
| `X1`～`X4`、普通查询及帮助 | 不改变序列、序号和计时。 |
| 重启、运动故障或通信丢字节故障 | 停止两轴并清除序列，不自动恢复跟踪。 |

用新的 `M/W` 定位或长序列替换旧序列时，由旧序列控制、但新定位没有涉及的轴先停止；例如用 `M180` 替换双轴 `W` 序列时，仰角停止，不遗留旧序列的运动。与序列无关的另一轴手动运动不因单轴 `M` 定位而被取消。`R/L/U/D/A/E` 则按表中规定只改变指定轴，不因取消序列而额外停止另一轴。

计时使用单调时钟和相对 `t0` 的绝对截止时刻，不把每次实际转动耗时累加到下一点，也不等待上一点到位。正常调度延迟不得累计漂移；若延迟已跨过另一个步进截止时刻，则停止两轴、清除序列并记录运动故障，不在恢复调度时突发补发多个过期点。查询、帮助和长行接收不能阻塞这个计时过程。

例如加载 `M010 150 140 100` 后，`N` 为 `=0001=0003`；收到 `T` 后的 10 秒下发 140 度，变为 `=0002=0003`；20 秒下发 100 度，变为 `=0003=0003`。这时不再有后续定时点，但并不保证机械位置已到 100 度。

### 11.4 校准交互

方位反馈使用 GPIO1 / ADC1_CH1，仰角反馈使用 GPIO0 / ADC1_CH0。固件自动使用芯片出厂校准数据将 ADC 计数修正为电压；两路外部反馈满量程均为 4.5V，分压后约 1.753V，分别对应方位 450 度、仰角 180 度。角度随反馈电压增加。`O` 保存方位零点，`O2` 保存仰角零点，互不修改另一轴。

各轴角度按 `θ = θ_FS × (Vadc − V0) / (V_FS − V0)` 分别换算。两轴 `V_FS` 均固定为 `4.5V × 3 / (4.7 + 3)`；`θ_FS` 分别为方位 450 度、仰角 180 度，`V0` 为该轴已保存零点。采样或有效跨度异常时拒绝保存，保留原零点。用户通过外部反馈电位器使 `F/F2` 读数达到 450 度或 180 度；显示过程中不更新固定参考或保存满量程点。

进入 `O/O2/F/F2` 前必须两轴停止、没有已加载序列，且待使用的轴已启用、ADC 采样有效；否则返回错误。同一时刻只允许一个校准会话，交互输入只由该会话解释。处于校准期间，其他会话只允许 `C/B/C2/N/H/H2/H3` 查询及 `A/E/S` 停止，其他控制、设置及校准命令返回错误。任一会话的停止命令都会退出当前校准；停止命令的响应返回其发起会话。

`O` 的完整提示为 `AZoffset\r\nare you sure? yes or no\r\n`，`O2` 将第一行换为 `ELoffset`。

| 等待确认时的输入或事件 | 行为 |
| --- | --- |
| `Y` 或 `YES` | 重新采样、校验并保存对应轴的零点；成功保存后输出 `Completed\r\n`，回到普通命令状态。采样、校验或保存失败则输出错误并退出，不改变原校准值。 |
| `N`、`NO` 或空行 | 取消，保留原校准值，返回一个 `CR`，回到普通命令状态。 |
| 其他非空输入 | 返回错误，继续等待确认，不把该输入交给普通命令解释器；不延长原确认期限。 |
| 提示发出后 30 秒未确认 | 取消并输出一次错误，回到普通命令状态。 |
| `A/E/S` | 立即退出校准，不保存零点，按普通停止命令执行并返回一个 `CR`。 |
| 发起会话断开 | 取消，不保存；不向其他会话转发提示或确认结果。 |

确认时保存的是确认瞬间的有效采样，不是进入提示时的旧读数。`Y`、`YES` 只在该会话等待确认时有效；普通命令状态下不接受这些独立命令。

确认超时或退出校准时，丢弃尚未提交的半行，并等待其终止 `CR` 后恢复普通解析，防止同一条输入被拆成校准回答和运动命令；没有半行时直接恢复。UART1 没有连接用于识别开关串口的握手线，不能检测主机关闭串口：零点确认依靠 30 秒期限取消，持续显示需要主机发送空行退出。会话断开取消规则适用于确实能检测到断开的通道。

`F/F2` 进入后立即输出第一帧，之后每 500ms 输出一帧，格式分别为 `AZ=aaa\r\n` 和 `AZ=aaa  EL=eee\r\n`。不补发积压的旧读数。发送空行结束显示并返回一个 `CR`；`A/E/S` 同样立即退出并执行停止。其他非空输入返回错误但继续显示。采样失效时输出一次错误并退出，不能继续显示旧值；会话断开时直接结束显示。

`F/F2` 的显示与退出均不自动移动转台，也不自动保存新的满量程；`Completed` 只用于零点已成功保存的确认。校准过程不接受行编辑按键，输入仍遵循第 11.1 节。

### 11.5 显示模式与角度映射

本项目初始模式选择 `P45`，保存的 360 度中心选项初始为 `N Center`。模式与中心选项断电保留；待使用轴缺少有效零点时仍禁止运动，不要求用户采集满量程点。`Y1`～`Y4` 不支持，返回错误，不能据此推断存在仰角调速。

定义 `p` 为零点修正后从逆时针机械端起、顺时针增加的实际行程角，范围为 `0`～`450` 度。仰角范围为 `0`～`180` 度。电气换算及行程限制固定，零点记录单独保存，`P36/P45/Z` 都不修改这些参数。以下公式仅定义本项目的协议坐标，中心切换会改变显示原点：

| 模式 | 方位响应值 |
| --- | --- |
| `P45` | 直接返回 `p`，保留超过 360 度的行程信息。 |
| `P36`、`S Center` | 返回 `p mod 360`。 |
| `P36`、`N Center` | 返回 `(p + 180) mod 360`，使行程 180 度处显示 0。 |

发送方位目标时使用上述换算的逆映射：450 度模式直接指定行程，360 度模式求出机械允许范围内的全部等价行程，选择距当前 `p` 最近的一个，等距时选择较小的 `p`；不存在合法解则整条命令报错。360 度模式下 `360` 与 `000` 表示同一方位，需要明确指定绕行位置时使用 450 度模式。长序列的首点按当前位置选解，后续点按前一点选出的行程连续选解，并在加载时一次完成范围校验。

协议数值四舍五入到整数度，恰好半度时向较大值取整；360 度响应取整后再次归一到 `000`～`359`。不得把越出机械范围或无效的反馈夹成合法角度后继续控制。

模式或中心的实际变更只在两轴停止、步进计时未运行且没有校准交互时接受；成功变更时清除已加载或已结束的序列，避免旧坐标被重新解释。重复设置当前模式只返回 `CR`，保留序列；450 度模式下 `Z` 只返回 `CR`，不修改保存的中心选项。

### 11.6 未启用轴与无效反馈

是否使用仰角由明确的设备配置决定，不能通过一次接近零的 ADC 读数自动判断。仰角未启用时：

- `B` 固定返回 `EL=000\r\n`，`C2` 保留仰角字段并填 `000`。
- `W` 的仰角必须全部为 `000`；允许这些命令控制方位，任一点仰角非零则整条拒绝。
- `U/D/O2/F2` 返回错误；`E` 和 `S` 仍可正常执行。

轴已启用但反馈无效时，不冒充 `000` 或继续返回旧位置。涉及该轴的角度查询返回错误，正在执行的运动按故障停止两轴并清除序列；普通 `N`、帮助和停止命令仍可使用。

本节规定的是协议层对已识别无效反馈的处理；模拟断线若与合法零点无法区分，不能声称仅靠串口协议即可可靠检测。
